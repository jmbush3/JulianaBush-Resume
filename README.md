# My First Website



### Project Goals

1. Learn HTML and CSS basics
2. Learn how to create responsive and accessible webpages
3. Use WCAG 2.1 A/AA/AAA requirements to guide design decisions



### File Structure

* /css - styling files
* /components - repeated page elements
* /images - images used in site
